# عيادات فلوريدا لطب وتجميل الأسنان

المشروع فيه جزئين:

- **الموقع العام** على `/`: الرئيسية، من نحن، احجز، خدماتنا، فريق العمل، قبل وبعد، آراء العملاء، تواصل معنا. نفس لاياوت الموقع القديم.
- **السيستم الداخلي** على `/admin`: تسجيل المرضى والخدمات، متابعة المدفوع والمتبقي، وتقرير يومي للخزنة. مش ظاهر في قائمة الموقع.

## الموقع العام

كل النصوص والأرقام والعناوين والفريق في `src/site/content.js`.

الحجز بيفتح واتساب برسالة جاهزة فيها بيانات المريض، فمفيش بيانات بتتخزن من الموقع العام.

### الصور (حطها في `public/images`)

| الملف | مكانه |
| --- | --- |
| `hero.jpg` | صورة الابتسامة في أول الصفحة الرئيسية |
| `banner.jpg` | خلفية عناوين الصفحات الداخلية (صورة الأسنان الغامقة) |
| `contact.jpg` | صورة خدمة العملاء في صفحة التواصل |
| `team/mahmoud.jpg`, `team/omar.jpg`, `team/ashrakat.jpg`, `team/karim.jpg` | صور الفريق (مربعة) |
| `cases/case1.jpg` ... `cases/case12.jpg` | حالات قبل وبعد (مربعة) |

لو صورة مش موجودة، بيظهر مكانها شكل بديل بدل صورة مكسورة.

## السيستم الداخلي

### الصفحات

- **الرئيسية**: حالات النهارده، المحصل النهارده والشهر، والفلوس اللي برا عند المرضى.
- **تسجيل مريض**: بيانات المريض + الخدمة + الدفع. لو الموبايل متسجل قبل كده، الخدمة بتتسجل على نفس الملف (ولو فرد تاني من العيلة بنفس الرقم تقدر تفتحله ملف جديد).
- **المرضى**: بحث بالاسم أو الموبايل، وفلتر "عليهم فلوس بس".
- **ملف المريض**: سجل الخدمات والدفعات، إضافة خدمة جديدة، أو تسجيل دفعة على المتبقي.
- **تقرير اليوم**: الحالات وتوزيعها على الأطباء وإجمالي الخزنة، مع زرار طباعة.

### تعديل الأطباء والخدمات والأسعار

من ملف `src/config.js`.

## التشغيل

```bash
npm install
npm run dev
```

## إعداد Firebase (مرة واحدة)

في Firebase Console (مشروع kufur-clinic) > **Firestore Database** > Rules: الصق محتوى ملف `firestore.rules` واضغط Publish.

> **تحذير:** السيستم من غير تسجيل دخول، يعني أي حد يوصل لرابط الموقع يقدر يشوف ويعدل ويمسح بيانات المرضى والحسابات.
> ما تشاركش الرابط، وقبل ما تدخل بيانات مرضى حقيقية بكميات كبيرة رجّع تسجيل الدخول (موجود في تاريخ git).

## الرفع على النت (Firebase Hosting، مجاني للحجم ده)

```bash
npm install -g firebase-tools
firebase login
npm run build
firebase deploy
```

الموقع هيبقى على `https://kufur-clinic.web.app`.

## شكل البيانات في Firestore

- `patients`: name, age, phone, address
- `visits`: patientId, patientName, date, service, doctor, total, paid, notes
- `payments`: patientId, patientName, date, amount (دفعات لاحقة على المتبقي)
